# 3D models

Place your Blender export here (e.g. **AxisHelper_01.glb**).

- App loads: `/models/AxisHelper_01.glb` (see `App.tsx` to change the path)
- Path on disk: `frontend/public/models/`

The model is displayed at world origin (0, 0, 0). If the file is missing, the server may return HTML and you’ll see an error in the console.
